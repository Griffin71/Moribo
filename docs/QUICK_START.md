## Getting Started

### 1. Opening the Website Locally

1. Navigate to the project folder: `c:\Moribo Financial Wellness Solution`
2. Open `index.html` in your web browser
3. The homepage will load with navigation to all pages

### 2. Website Structure

```
Moribo Financial Wellness Solution/
├── index.html              (Homepage)
├── css/                    (Stylesheets)
├── js/                     (JavaScript)
├── pages/                  (Main pages)
├── docs/                   (Documentation)
└── assets/                 (Images/media)
```

## Customization Tips

### Change Colors
Edit `/css/theme.css` to modify the blue color scheme:
```css
--primary-blue: #0055a4
--secondary-blue: #0066cc
--light-blue: #e8f2ff
```

### Update Company Information
Edit the footer in any HTML file to change:
- Company name
- Contact email
- Address
- Phone number

### Modify Content
1. Open the relevant HTML file
2. Find the section you want to edit
3. Update the text content
4. Save the file
5. Refresh your browser

### Add New Pages
1. Create a new `.html` file in `/pages` folder
2. Copy structure from existing page
3. Update content
4. Add link to navigation menu

## Troubleshooting

### Images Not Loading
- Check if files are in `/assets` folder
- Verify file paths in HTML

### Styles Not Applied
- Clear browser cache (Ctrl+F5)
- Check CSS file paths in HTML `<link>` tags

### Navigation Links Not Working
- Verify file paths match folder structure
- Check relative paths (e.g., `../pages/about.html`)

### Maps Not Displaying
- Check internet connection
- Verify iframe embed codes are correct
