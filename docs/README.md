## How to Use

### Opening the Website Locally
1. Navigate to the project folder
2. Open `index.html` in your web browser
3. Use the navigation menu to browse pages

### Customization

#### Colors
Edit `/css/theme.css` to change the color scheme. All colors are stored in CSS variables under `:root`.

#### Text Content
Edit the respective `.html` files to update content.

#### Branding
- Update the logo in the navigation by editing the `.logo` element in any HTML file
- Update company name and contact info in the footer

### Adding New Pages
1. Create a new `.html` file in the `/pages` folder
2. Copy the structure from an existing page
3. Update the content
4. Add navigation links to all pages
